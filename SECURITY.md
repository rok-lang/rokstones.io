# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues or pull requests.

Use GitHub's private vulnerability reporting: on this repository, open the
**Security** tab and choose **Report a vulnerability**. You can also email security@rok-lang.org.

To report a **malicious or compromised stone** in the registry, use the same
private channel; include the stone name, version, and what you observed. We can
yank an affected version while it is investigated.

We will acknowledge the report, work with you on a fix, and credit you in the
advisory unless you prefer otherwise.

## Supported versions

rok is pre-1.0. Security fixes land on the latest 0.x release.
